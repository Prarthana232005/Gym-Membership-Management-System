

\# Gym Membership Management System



\## About the Project

This is a simple console-based Java application used to manage gym members, membership plans, attendance and trainers.



\## Features

1\. Register New Member

2\. View All Members

3\. View Membership Plans

4\. Select Membership Plan

5\. Renew Membership

6\. Mark Attendance

7\. View Attendance

8\. Add Trainer

9\. Allot Trainer

10\. View Trainers

11\. Exit



\## Technologies Used

\- Java

\- OOP Concepts

\- ArrayList

\- HashMap

\- Linked List

\- Custom Exceptions



\## How to Run

1\. Open Command Prompt.

2\. Navigate to the project folder.

3\. Compile using javac Main.java.

4\. Run using java Main.
